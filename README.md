# ROI 智能计算器

Windows 桌面端 ROI 智能计算器，面向电商广告投放的盈亏平衡与广告承载能力测算。

## 功能

- 商品售价、商品成本、商品运费、运费险
- 平台扣点、预计退款率
- 退货商品“可再次销售 / 成本全部损失”两种口径
- 实时计算最低保本 ROI
- 每单可承受广告费
- 预计平台扣点
- 推广前毛利率
- 一键重置
- 一键复制测算结果
- 自动保存上次输入参数
- Windows 单文件 EXE

## 计算口径

- 预计实收 = 商品售价 × (1 - 预计退款率)
- 预计平台扣点 = 预计实收 × 平台扣点率
- 有效商品成本：
  - 可再次销售：商品成本 × (1 - 预计退款率)
  - 成本全部损失：商品成本
- 每单可承受广告费 = 预计实收 - 预计平台扣点 - 有效商品成本 - 商品运费 - 运费险
- 保本 ROI = 商品售价 ÷ 每单可承受广告费
- 推广前毛利率 = 每单可承受广告费 ÷ 商品售价
