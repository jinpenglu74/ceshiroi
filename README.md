# ROI 智能计算器

Windows 桌面端 ROI 智能计算器，面向电商投放场景，根据商品售价、商品成本、运费、运费险、平台扣点、预计退款率与退货成本口径，实时测算保本 ROI、每单可承受广告费、预计平台扣点和推广前毛利率。

## 版本

v1.0.0

## 运行

发布版请直接运行 `ROI智能计算器-v1.0.0.exe`。

## 计算口径

- 预计实收 = 商品售价 × (1 - 预计退款率)
- 预计平台扣点 = 预计实收 × 平台扣点率
- 有效商品成本：
  - 可再次销售：商品成本 × (1 - 预计退款率)
  - 成本全部损失：商品成本
- 每单可承受广告费 = 预计实收 - 预计平台扣点 - 有效商品成本 - 商品运费 - 运费险
- 保本 ROI = 商品售价 ÷ 每单可承受广告费
- 推广前毛利率 = 每单可承受广告费 ÷ 商品售价

## 工程质量
